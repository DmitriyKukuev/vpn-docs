# Подключение к AmneziaVPN через файл конфигурации

## 1. Установите приложение

Выберите своё устройство:

- [Android — Google Play](https://play.google.com/store/apps/details?id=org.amnezia.vpn)
- [Windows — GitHub Releases](https://github.com/amnezia-vpn/amnezia-client/releases/download/4.8.19.0/AmneziaVPN_4.8.19.0_x64.exe)
- [macOS — GitHub Releases](https://github.com/amnezia-vpn/amnezia-client/releases/download/4.8.19.0/AmneziaVPN_4.8.19.0_macos.pkg)
- [iOS — App Store](https://apps.apple.com/ru/app/amneziawg/id6478942365)

## 2. Сохраните файл конфигурации

Сохраните полученный файл конфигурации на устройство, которое хотите подключить. Обычно его название заканчивается на `.conf`.

## 3. Добавьте подключение

### AmneziaVPN (Android, Windows, macOS) {#android-windows-macos}

1. Откройте AmneziaVPN. Если это первый запуск, нажмите `Приступим`.

2. На экране добавления подключения нажмите `Файл с настройками подключения`.

3. В проводнике или приложении `Файлы` выберите файл конфигурации.

4. Убедитесь, что выбран нужный файл, и нажмите `Подключиться`.

   ![Импорт файла конфигурации в AmneziaVPN](/images/amneziavpn-file/amneziavpn-1.webp)

5. На главном экране ещё раз нажмите большую кнопку `Подключиться`.

   ![Подключение в AmneziaVPN](/images/amneziavpn-file/amneziavpn-2.webp)

### AmneziaWG (iOS) {#ios}

1. Откройте приложение AmneziaWG и нажмите `Добавить туннель`.

2. Выберите `Создать из файла или архива` и укажите файл конфигурации.

3. Когда iPhone запросит разрешение на добавление VPN-конфигурации, нажмите `Разрешить`.

4. Включите переключатель рядом с названием конфигурации.

   ![Импорт файла конфигурации в AmneziaWG](/images/amneziavpn-file/amneziawg.webp)
