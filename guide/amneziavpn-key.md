# Подключение к AmneziaVPN через ключ в виде текста

## 1. Установите приложение

Выберите своё устройство:

- [Android — Google Play](https://play.google.com/store/apps/details?id=org.amnezia.vpn)
- [Windows — GitHub Releases](https://github.com/amnezia-vpn/amnezia-client/releases/download/5.0.0.5/AmneziaVPN_5.0.0.5_windows_x64.exe)
- [macOS — GitHub Releases](https://github.com/amnezia-vpn/amnezia-client/releases/download/5.0.0.5/AmneziaVPN_5.0.0.5_macos_x64.pkg)
- [iOS — App Store](https://apps.apple.com/ru/app/defaultvpn/id6744725017)

## 2. Скопируйте ключ

Найдите ключ в полученном сообщении. Обычно он начинается с `vpn://`.

Скопируйте его целиком на устройство, которое хотите подключить. Если захватить не весь текст или лишние символы, приложение сообщит об ошибке.

## 3. Добавьте подключение

### AmneziaVPN (Android, Windows, macOS) {#android-windows-macos}

1. Откройте AmneziaVPN и нажмите `➕` или `Приступим`, если в приложении ещё нет других подключений.

2. Нажмите `Вставить` возле поля для ключа, затем `Продолжить` и `Подключиться`.

   ![Импорт ключа в AmneziaVPN](/images/amneziavpn-key/amneziavpn-1.webp)

3. После добавления нажмите кнопку включения VPN.

   ![Вставка ключа в AmneziaVPN](/images/amneziavpn-key/amneziavpn-2.webp)

### DefaultVPN (iOS) {#ios}

1. Откройте DefaultVPN.

2. Нажмите `➕`, затем `Вставить` под полем для ключа и `Добавить`.

3. После добавления нажмите кнопку включения VPN.

   ![Импорт ключа в DefaultVPN](/images/amneziavpn-key/defaultvpn.webp)
